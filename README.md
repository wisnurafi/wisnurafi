### Hi, I'm Wisnu Rafi

I'm a systems software engineer and **Security Engineer** at **Beyondsoft Singapore**. I build low-level systems where there's nothing underneath to catch a mistake then I attack them to make sure they hold up when a real attacker shows up.

I'm the kind of engineer who gets curious when something only breaks for one user, on one machine, at the worst possible time. I like messy problems because they force the real story out of the system.

My work lives close to the metal: **Windows internals**, **binary analysis**, **game security research**. C and C++ are home. C#, Rust, Python and TypeScript cover the rest. On any given day you'll find Ghidra, IDA Pro, x64dbg, WinDbg or Wireshark open on my screen.

**How I work**

- I trust a bug after I can reproduce it twice.
- A finding isn't finished until the fix is obvious.
- No source code is fine. Behavior leaves clues.

*Ship reliable systems. Then break them.*
